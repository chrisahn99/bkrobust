\section{The candidates}

Thirteen. Each is printed with the numbers that exist today; an unrun cell is marked and never left
blank. Under each float is the file the numbers were read from, and after it a fixed block: what
the table presents, the claims it verifies, the prior work that gets a number inside it, the
objection it invites, and what it would cost to finish.

\vspace{4pt}
\noindent\emph{Draft caption.} Five instruments an analyst can compute without the
data-generating graph, ordered by cost. An instrument over-certifies when it declares an adjustment
set safe at a depth at which the set is in fact invalid. Over 3{,}014 queries on 27 published
network structures, under eleven knowledge conditions ranging from chance orientations to truthful
ones, a certificate denominated in elementary graph revisions over-certifies on 39 queries and a
certificate denominated in the analyst's own claims on none. The zero follows from the criterion
rather than from the sample: if the committed set is invalid at the truth and the analyst asserted
$w$ false claims, retracting those $w$ claims leaves a graph the truth extends, so the claim radius
is at most $w$ whenever the search reaches that depth.
